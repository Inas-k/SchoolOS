# Skooly clone

**Target URL:** https://getskooly.com/

A rebuild of the Skooly marketing home page (Vite + React 19 + Tailwind v4), matched to the live site by measured computed styles.

## Run

```bash
npm install
npm run dev        # http://127.0.0.1:4173
npm run build      # production build -> dist/
npm run preview    # serve the build on http://127.0.0.1:4173
```

## What was cloned

- **Route:** `/` (home) only. See "Known gaps".
- **Breakpoints:** 375, 640, 768, 1023, 1024, 1280, 1536 and 1920 wide. Page height matches the original exactly at 375 (12016px), 768 (8119px) and 1920 (7857px).
- **Sections:** sticky header, hero with stacked product windows, stats band, problem, solution, shared spine, copilot, testimonials, final CTA, footer, floating chat widget.
- **States:** Features and Pricing menus (hover, click, close delay), header scroll shadow, hero window switch, every button and link hover, language pill, chat panel (open, field focus), mobile and tablet menus.
- **Motion (values measured on the live page):**
  - Hero stagger: fade-up, 500ms, `cubic-bezier(.22,1,.36,1)`, delays 0/120/240/360/480ms.
  - Scroll reveals: IntersectionObserver threshold 0.05, 100ms stagger.
  - Stat counters: threshold 0.3, 2000ms ease-out-cubic count from 0.
  - Background orbs: `orbFloat` 22s and 28s (-5s delay), 80px blur.
  - Header: shadow after 8px of scroll, 300ms transition. Menus close 150ms after the pointer leaves.
  - Chat widget auto-opens once per browser (25s active time, 55% scroll, or pointer leaving through the top). Skipped on touch devices. `?widgetdebug` shortens it to 2s.
  - `prefers-reduced-motion` handled as on the original.
- **Stack of the original:** Next.js (Turbopack), Tailwind v4, CSS animations and IntersectionObserver. No canvas, WebGL or scroll library.

## Substitutions

| Original | Replacement | Why |
|---|---|---|
| Plus Jakarta Sans and Figtree woff2 files | Same families from Fontsource (`@fontsource-variable/*`) | Open CDN package, not the original's files. Fallback metrics (`size-adjust`, ascent/descent) are the original's measured values. |
| Product dashboard screenshots (PNG) | SVG dashboards drawn in code (`DashboardMock.jsx`), same 1600x865 ratio and brand colours, invented sample figures | Not downloading the original's images. |
| "skooly" wordmark PNG | Hand-drawn SVG paths (`assets.js`), same 109x47 box and `#d01858` | Same reason. It is visibly a close redraw, not the exact logo. |
| Customer logos | Initials tiles | Same reason. |
| App Store and Google Play glyphs, chat icon | Lucide `Apple` and `Play` icons, redrawn chat icon | Brand glyphs are not copied. |
| Opacity-colour utilities | `src/color-parity.css`, generated by `tools/gen-color-parity.mjs` | The original's build writes `lab()` values and Tailwind writes `color-mix()`. Same colour, different serialization. |

External links (login, register, help centre, app stores, YouTube) still point at the real Skooly service. Change them in `src/config.js`.

## Final assertion results

Run with the stack up on `127.0.0.1:4173`. Ground truth is the live site's `getComputedStyle` values, read with Playwright. Every element is compared on 48 properties plus its box size.

| Check | Result |
|---|---|
| Build (`npm run build`) | clean |
| Style gate, 1920px (`_method/scripts/assert-styles.mjs`) | 20550 / 20550 passed, 0 failed |
| Style gate, 768px | 19800 / 19800 passed, 0 failed |
| Style gate, 375px | 19800 / 19800 passed, 0 failed |
| Strict gate (exact string match, repo gate only checks the first number of composite values) | 0 failures, 0 missing, 0 extra elements |
| Interaction states (`tools/states.mjs`, 25 states, full computed styles of every element) | 23 pass, 2 have 2 diffs each (the chat footnote, see below) |
| Reveal threshold (`tools/threshold.mjs`, 28 elements) | pass, identical on both sites |
| Motion (`tools/motion.mjs`) | load animations (7), orb animation, transitions, reveal classes and delays, counter end values all equal |

Commands: `node tools/gate.mjs 1`, `node tools/states.mjs`, `node tools/motion.mjs`, `node tools/threshold.mjs`.

## Known gaps

- **Only the home page is built.** The original has about 80 routes. Links to other paths show a "not part of this clone" placeholder page.
- **Imagery is not identical** (see Substitutions). Dashboard contents and the logo differ from the original by design.
- **Chat footnote.** The original says "Protected by reCAPTCHA". This form has no reCAPTCHA and sends nothing, so the line reads "Demo form: nothing is sent or stored." That is the only text difference and the cause of the 2 state diffs.
- **Language selector** is present but inert. Localised pages (ms, ar, es, pt, fr, id) and right-to-left layout are not built.
- **Not included:** Google Ads tags, reCAPTCHA, the original's JSON-LD, hreflang alternates, `og:image`, favicon (the clone uses a simple generated one), server rendering and route prefetching.
- **Measurement caveat.** Chromium sometimes reports a stale `0px` for the auto margins of two hero boxes on the original. The snapshot scripts force a relayout before reading, and the state harness ignores margin differences when position and width already match. Widths and positions are compared and equal.
- **Scroll-flip positions** of individual reveals cannot be compared to the pixel because observer timing jitters by tens of pixels on both sites. The deterministic threshold test replaces that.
- Checked in Chromium only.
